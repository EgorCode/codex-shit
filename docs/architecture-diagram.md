# Диаграммы архитектуры

## Архитектура высокого уровня

```
┌────────────────────────────────────────────────────┐
│                    Пользователь                      │
└────────────────────┬───────────────────────────────┘
                     │
                     ▼
┌────────────────────────────────────────────────────┐
│              Next.js Frontend (Vercel)              │
│  ┌──────────────────────────────────────────────┐  │
│  │  App Router Pages                            │  │
│  │  - Home                                      │  │
│  │  - Wizard                                    │  │
│  │  - Comparison                                │  │
│  └──────────────────────────────────────────────┘  │
└────────────────────┬───────────────────────────────┘
                     │
                     ▼
┌────────────────────────────────────────────────────┐
│           Next.js API Routes (Vercel)              │
│  ┌──────────────────────────────────────────────┐  │
│  │  /api/wizard                                 │  │
│  │  /api/forms                                  │  │
│  │  /api/documents                              │  │
│  └──────────────────────────────────────────────┘  │
└────────────────────┬───────────────────────────────┘
                     │
         ┌───────────┴───────────┐
         │                       │
         ▼                       ▼
┌──────────────────┐    ┌──────────────────┐
│   PostgreSQL     │    │    Strapi CMS    │
│   (Railway)      │    │    (Railway)     │
└──────────────────┘    └──────────────────┘
```

## Поток данных мастера подбора

```
┌─────────────────────┐
│  Пользователь       │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│  Wizard Component   │ ◄── Вопросы из wizard-data.ts
└──────────┬──────────┘
           │
           │ Ответы пользователя
           ▼
┌─────────────────────┐
│  Calculate Result   │ ◄── Алгоритм подсчета баллов
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│  Отображение        │
│  результата         │
└─────────────────────┘
```

## Компоненты и их взаимодействие

```
┌───────────────────────────────────────────┐
│           WizardComponent                 │
│  ┌─────────────────────────────────────┐  │
│  │  State: step, answers, result       │  │
│  └─────────────────────────────────────┘  │
│  ┌─────────────────────────────────────┐  │
│  │  Functions:                         │  │
│  │  - handleAnswer()                   │  │
│  │  - handleNext()                     │  │
│  │  - handlePrevious()                 │  │
│  │  - handleReset()                    │  │
│  └─────────────────────────────────────┘  │
└───────────────────────────────────────────┘
             │
             ▼
┌───────────────────────────────────────────┐
│         wizard-data.ts                    │
│  ┌─────────────────────────────────────┐  │
│  │  - questions[]                      │  │
│  │  - comparison[]                     │  │
│  │  - wizardResults[]                  │  │
│  │  - calculateWizardResult()          │  │
│  └─────────────────────────────────────┘  │
└───────────────────────────────────────────┘
```
