### Frontend
- ⚡ **Next.js 14** с App Router
- ⚛️ **React 18** с Server Components
- 📘 **TypeScript** для типобезопасности
- 🎨 **Tailwind CSS** для стилизации
- 🔤 **Inter Font** с поддержкой кириллицы

- 📝 ESLint для проверки кода

## 🎓 Алгоритм мастера подбора

### Система баллов
Каждый ответ добавляет баллы к одной из форм:
- **НПД**: лучше для фрилансеров с малым оборотом
- **ИП**: универсальный вариант для малого бизнеса
- **ООО**: для крупного бизнеса и партнёрств

### Вопросы:
1. **Оборот** - ключевой фактор для лимитов
2. **Клиенты** - физлица vs юрлица
3. **Сотрудники** - необходимость найма
4. **Партнёры** - соучредители
5. **Риски** - защита имущества
