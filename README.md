# Айт-помощник для начинающих предпринимателей

Современная платформа, которая помогает человеку на старте предпринимательского пути выбрать оптимальную организационно-правовую форму (НПД, ИП, ООО), разобраться в налогах и обязательствах, получить готовые шаблоны документов и инструменты для расчётов.

## 🚀 Основные возможности

- **Мастер подбора формы бизнеса** — интерактивный опросник из 5-7 вопросов
- **Сравнение форм бизнеса** — фильтруемая таблица с детальным сравнением
- **Библиотека документов** — 30+ шаблонов для регистрации и ведения бизнеса
- **Калькуляторы налогов** — НПД, УСН, страховые взносы
- **База знаний** — статьи, гайды и чек-листы
- **Персонализация** — сохранение результатов и избранного

## 🎯 Целевая аудитория

- Люди, планирующие запуск бизнеса (за 6 месяцев до старта)
- Фрилансеры и самозанятые, переходящие на ИП/ООО
- Партнёрские проекты (2-5 соучредителей)

## 🛠 Технологический стек

- **Frontend:** Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes, Prisma ORM
- **База данных:** PostgreSQL, Redis
- **CMS:** Strapi
- **Аутентификация:** Supabase Auth
- **Хостинг:** Vercel, Railway

## 🚀 Быстрый старт

### Требования

- Node.js 18.17+
- PostgreSQL 14+
- Redis 6+

### Установка

1. Клонируйте репозиторий

   ```bash
   git clone <repository-url>
   cd yurgid-business
   ```

2. Установите зависимости

   ```bash
   npm install
   ```

3. Настройте переменные окружения

   ```bash
   cp .env.example .env.local
   # Отредактируйте .env.local с вашими данными
   ```

4. Настройте базу данных

   ```bash
   npx prisma migrate dev
   npx prisma db seed
   ```

5. Запустите проект

   ```bash
   npm run dev
   ```

6. Откройте http://localhost:3000

## 🏗️ Архитектура

Проект построен по принципу JAMstack с разделением на фронтенд и бэкенд:

- **Frontend** — Next.js с App Router для SSR и оптимизации
- **Backend** — Next.js API Routes для серверной логики
- **CMS** — Strapi для управления контентом
- **База данных** — PostgreSQL для структурированных данных
- **Кеширование** — Redis для улучшения производительности

## 📊 Модели данных

Основные сущности:

- **User** — пользователи
- **BusinessForm** — формы бизнеса (НПД, ИП, ООО)
- **Document** — шаблоны документов
- **Article** — статьи и гайды
- **Favorite** — избранное пользователей
- **WizardResult** — результаты мастера подбора
