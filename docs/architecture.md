# Архитектура проекта

## Обзор

Проект построен на основе современного стека технологий с использованием Next.js 14 и App Router.

## Структура проекта

```
yurgid-business/
├── src/
│   ├── app/              # Next.js App Router страницы
│   │   ├── page.tsx      # Главная страница
│   │   ├── wizard/       # Мастер подбора
│   │   ├── comparison/   # Сравнение форм
│   │   ├── layout.tsx    # Корневой layout
│   │   └── globals.css   # Глобальные стили
│   ├── components/       # React компоненты
│   │   └── WizardComponent.tsx
│   ├── lib/              # Утилиты и хелперы
│   │   ├── wizard-data.ts
│   │   └── utils.ts
│   ├── types/            # TypeScript типы
│   │   └── index.ts
│   └── store/            # Zustand state management
├── prisma/               # Prisma схема и миграции
│   └── schema.prisma
├── public/               # Статические файлы
└── docs/                 # Документация
```

## Технологический стек

### Frontend
- **Next.js 14**: React-фреймворк с App Router для SSR и SSG
- **React 18**: Библиотека для построения UI
- **TypeScript**: Типизированный JavaScript
- **Tailwind CSS**: Utility-first CSS фреймворк

### Backend
- **Next.js API Routes**: Серверные эндпоинты
- **Prisma ORM**: Работа с базой данных
- **PostgreSQL**: Реляционная база данных

### State Management
- **Zustand**: Легковесное управление состоянием

## Основные функции

### 1. Мастер подбора формы бизнеса
- Интерактивный опросник из 5 вопросов
- Алгоритм подсчета баллов для каждой формы
- Персонализированные рекомендации

### 2. Сравнение форм бизнеса
- Детальная таблица сравнения НПД, ИП, ООО
- Фильтрация по параметрам

### 3. Библиотека документов (в разработке)
- Шаблоны документов
- Категоризация
- Поиск

### 4. Калькуляторы (в разработке)
- Расчет налогов
- Страховые взносы

## Принципы разработки

1. **Server-First**: Использование серверных компонентов по умолчанию
2. **Type Safety**: Строгая типизация с TypeScript
3. **Performance**: Оптимизация загрузки и рендеринга
4. **Accessibility**: Доступность для всех пользователей
5. **Mobile-First**: Адаптивный дизайн
