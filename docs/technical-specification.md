# Техническое задание

## Цель проекта
Создать цифрового помощника для начинающих предпринимателей, который помогает выбрать форму ведения бизнеса и подготовиться к запуску.

## Основные модули
1. **Мастер подбора** — интерактивный wizard
2. **Сравнение форм** — таблица с параметрами
3. **Библиотека документов** — шаблоны и гайды
4. **Калькуляторы** — налоговые расчеты

## Требования к интерфейсу
- Поддержка мобильных устройств
- Интуитивно понятная навигация
- Современный визуальный стиль

## Интеграции
- Strapi CMS для контента
- Supabase Auth для аутентификации (план)
- PostgreSQL + Prisma для данных

## Этапы
1. MVP — мастер подбора и сравнение
2. Персонализация и избранное
3. Платные функции и интеграции
